Fitness Tracker Website Blueprint

7-Entity Version

Project Overview

This project is a fitness tracker website built with ASP.NET Core, Razor Pages, Entity Framework Core, and authentication. The website allows users to track workouts, exercises, meals, and fitness goals.

This version intentionally uses exactly 7 entities.

Seven Entities

  1. ApplicationUser
  2. UserProfile
  3. Workout
  4. Exercise
  5. WorkoutExercise
  6. Meal
  7. Goal

Requirement Checklist

Requirement How the Design Meets It
Include authentication Use ASP.NET Core Identity with an ApplicationUser model.
Minimum of 5 entities The design includes exactly 7 entities.
Relationships Entities are connected through user ownership and workout/exercise tracking.
4 out of 5 entities must be related to at least one other entity All 7 entities are related to at least one other entity.
2 entities have multiple other entities in it ApplicationUser contains many workouts, meals, and goals. Workout contains many workout exercises.
2 relationships must be one-to-many Examples: one user has many workouts, one user has many meals, one user has many goals, and one workout has many workout exercises.
Include a search page Add a Search.cshtml page to search workouts, meals, goals, and exercises.
Include 2 custom pages such as statistics Add a Statistics.cshtml page and a GoalSummary.cshtml page.

Entity Purpose Summary

Entity Purpose Related To
ApplicationUser Authentication user account UserProfile, Workout, Meal, Goal
UserProfile Stores personal fitness profile information ApplicationUser
Workout Stores workout sessions ApplicationUser, WorkoutExercise
Exercise Stores exercise library information WorkoutExercise
WorkoutExercise Connects workouts to exercises and stores sets, reps, and weight Workout, Exercise
Meal Stores food and nutrition entries ApplicationUser
Goal Stores user fitness goals ApplicationUser

Relationship Summary

Relationship Type Explanation
ApplicationUser → UserProfile One-to-One One user has one fitness profile.
ApplicationUser → Workouts One-to-Many One user can have many workouts.
ApplicationUser → Meals One-to-Many One user can log many meals.
ApplicationUser → Goals One-to-Many One user can create many fitness goals.
Workout → WorkoutExercises One-to-Many One workout can contain many workout exercise records.
Exercise → WorkoutExercises One-to-Many One exercise can appear in many workout exercise records.

7. Goal.cs

using System;
using System.ComponentModel.DataAnnotations;
using System.ComponentModel.DataAnnotations.Schema;

namespace FitnessTracker.Models
{
    public class Goal
    {
        public int ID { get; set; }

        public string? ApplicationUserId { get; set; }

        public ApplicationUser? ApplicationUser { get; set; }

        [Display(Name = "Goal Name")]
        public string GoalName { get; set; } = string.Empty;

        [Display(Name = "Goal Type")]
        public string? GoalType { get; set; }

        [Display(Name = "Target Value")]
        public double? TargetValue { get; set; }

        [Display(Name = "Current Value")]
        public double? CurrentValue { get; set; }

        [Display(Name = "Target Date")]
        public DateTime? TargetDate { get; set; }

        [NotMapped]
        public bool IsCompleted => CurrentValue.HasValue
                                   && TargetValue.HasValue
                                   && CurrentValue.Value >= TargetValue.Value;
    }
}

ApplicationDbContext Example

using FitnessTracker.Models;
using Microsoft.AspNetCore.Identity.EntityFrameworkCore;
using Microsoft.EntityFrameworkCore;

namespace FitnessTracker.Data
{
    public class ApplicationDbContext : IdentityDbContext<ApplicationUser>
    {
        public ApplicationDbContext(DbContextOptions<ApplicationDbContext> options)
            : base(options)
        {
        }

        public DbSet<UserProfile> UserProfiles { get; set; }

        public DbSet<Workout> Workouts { get; set; }

        public DbSet<Exercise> Exercises { get; set; }

        public DbSet<WorkoutExercise> WorkoutExercises { get; set; }

        public DbSet<Meal> Meals { get; set; }

        public DbSet<Goal> Goals { get; set; }
    }
}

Search Page

Create a custom search page named Search.cshtml. This page can search across workouts, meals, goals, and exercises.

Searchable Fields

  • Workout name
  • Workout type
  • Exercise name
  • Muscle group
  • Meal name
  • Goal name
  • Goal type

Example Search Logic

public string? SearchTerm { get; set; }

public IList<Workout> Workouts { get; set; } = new List<Workout>();

public async Task OnGetAsync(string? searchTerm)
{
    SearchTerm = searchTerm;

    var query = _context.Workouts.AsQueryable();

    if (!string.IsNullOrEmpty(searchTerm))
    {
        query = query.Where(w => w.WorkoutName.Contains(searchTerm)
                              || (w.WorkoutType != null && w.WorkoutType.Contains(searchTerm)));
    }

    Workouts = await query.ToListAsync();
}

Custom Page 1: Statistics Page

Create a custom page named Statistics.cshtml. This page summarizes the user's fitness activity.

Possible Statistics

  • Total workouts
  • Total workout calories burned
  • Average workout duration
  • Total meals logged
  • Total goals created

Example Statistics Logic

TotalWorkouts = await _context.Workouts.CountAsync();

TotalCaloriesBurned = await _context.Workouts
    .SumAsync(w => w.CaloriesBurned ?? 0);

AverageWorkoutDuration = await _context.Workouts
    .AverageAsync(w => w.DurationMinutes ?? 0);

TotalMeals = await _context.Meals.CountAsync();

TotalGoals = await _context.Goals.CountAsync();

Custom Page 2: Goal Summary Page

Create a custom page named GoalSummary.cshtml. This page summarizes the user's fitness goals.

Possible Goal Summary Data

  • Total goals
  • Completed goals
  • Incomplete goals
  • Goals near target date
  • Average progress toward goals

Example Goal Summary Logic

CompletedGoals = await _context.Goals
    .CountAsync(g => g.CurrentValue >= g.TargetValue);

IncompleteGoals = await _context.Goals
    .CountAsync(g => g.CurrentValue < g.TargetValue);

TotalGoals = await _context.Goals.CountAsync();
